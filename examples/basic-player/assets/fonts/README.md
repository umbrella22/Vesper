# Desktop UI font

`Ubuntu-Light.ttf` is the unmodified Ubuntu Light typeface distributed with
`epaint_default_fonts` 0.37.0. It matches EmbedScope Inspector's proportional
font. Copyright 2011 Canonical Ltd. The font remains under the Ubuntu Font
Licence 1.0 in [UFL.txt](UFL.txt), separate from Vesper's Apache-2.0 source.

Source: <https://github.com/emilk/egui/tree/0.37.0/crates/epaint_default_fonts/fonts>

Keep the font and its licence together in source distributions and preserve the
licence when distributing a desktop executable that embeds the font. Optional
installed system fonts are read locally for missing glyphs and are not bundled.
