# Vesper FFmpeg Packaging Contract

## Licensing

- Vesper source remains Apache-2.0.
- FFmpeg-backed artifacts retain FFmpeg's license, notices, corresponding
  source, configure metadata, and LGPL relinking obligations.
- Never add `--enable-gpl` or `--enable-nonfree` without an explicit documented
  release decision.
- Changes to flags, external libraries, bundled payloads, or remux packaging
  must update `THIRD_PARTY_NOTICES.md`, relevant README files, and release
  metadata when applicable.

## Profile Source Of Truth

The checked-in FFmpeg profile document is the source of truth. Profiles describe
capabilities, while platform selectors describe build targets. Preserve ordered
deduplicated lists and apply platform overrides after inheritance. Validate
network/OpenSSL restrictions and all CLI overlays before building.

Ordinary FFmpeg source builds resolve patches within the 9.0 series; the
release source lock remains 9.0.2. Android DASH builds use the libxml2 2.15
series, and optional OpenSSL overlays use the 3.5 LTS series. Every ordinary
build checks upstream even when archives are cached and selects the highest
matching patch available upstream or locally. Missing versioned archives are
downloaded into the shared cache. Standard profiles keep network access and
OpenSSL disabled in the FFmpeg runtime.

An unavailable index falls back to the highest matching cached patch. Without
a cached dependency archive, an unsuccessful lookup preserves its cause and
must never return a series as an exact release. Exact version overrides take
precedence over series selectors and skip discovery. Known libxml2 2.15.4 and
OpenSSL 3.5.9 archive digests remain enforced for those versions; newer patches
can be resolved without a checked-in digest and record their actual source
SHA-256. Explicit checksum overrides remain supported.

Android dependency reuse requires matching source identity, ABI/API level, and
installed pkg-config/header/library digests in
`vesper-dependency-build-metadata.txt`. Android FFmpeg build metadata includes
those records, so dependency upgrades or changed dependency sources/builds
invalidate stale FFmpeg output even when the capability profile hash is unchanged.

Typical fields include `extends`, `libraries`, `demuxers`, `muxers`,
`protocols`, `parsers`, `bsfs`, `tls`, `forbid_network`, `forbid_openssl`, and
`platform_overrides`.

## Artifact Split

- Android `vesper-player-kit-ffmpeg-runtime` is the only AAR that carries
  FFmpeg runtime libraries/assets.
- Relay and download remux plugins carry glue binaries only; they must not
  bundle duplicate `libav*`, `libsw*`, `libxml2*`, `libssl*`, or `libcrypto*`.
- The SourceNormalizer FFmpeg AAR/framework also carries plugin glue and profile
  metadata only. It uses the shared runtime closure and must not duplicate
  FFmpeg components.
- Runtime and plugin profile hashes must match.
- Plugin packages declare the FFmpeg closure as runtime dependency metadata.
  Catalog import records that metadata, resolver/plan stages select one
  compatible closure, and executable loading verifies the selected artifact;
  no live FFmpeg owner belongs in catalog or plan state.
- The baseline host kit must remain usable without optional FFmpeg payloads.
- iOS separates the FFmpeg component frameworks from optional plugin frameworks
  and verifies provenance for each slice.

## Relay Remux

Relay remux is remux-only: no transcoding, DRM, site-specific headers, origin
URL rewriting, or default FFmpeg network access. Prefer host/platform fetching
and local file/pipe input. Preserve stable diagnostics for missing runtime,
profile mismatch, unsupported device/layout/encryption, host fetch failure,
open/muxer failure, timeout, range readiness, and cancellation.

## Gradle Input Ownership

- A directory generated by the task or its CLI is task local state/output, not
  an input that must exist before execution. Declare the source manifests,
  profiles, policies, tools, ABI, and build mode that generate it.
- When skip-runtime mode consumes an externally prepared FFmpeg directory, that
  directory is a required input. Register the skip flag as an input property so
  changing modes invalidates stale task outputs.
- Do not hide a truly required input behind a configuration-time
  `isDirectory` check. A missing optional/generated directory may proceed; a
  missing required prebuilt must fail with an explicit diagnostic.
- Validate this contract by executing the real build task in a checkout where
  the generated directory is initially absent. `tasks`, `help`, and `--dry-run`
  do not exercise Gradle input snapshotting.

## Validation

Use the Rust CLI for profile listing, dry-runs, verification, and mobile
no-remux checks. Local Android Gradle commands use the cached project
distribution and project-local dependency cache; never trigger an online
wrapper download. Allow one dependency refresh, then retry the identical
command once with `--offline` after the first network failure.
